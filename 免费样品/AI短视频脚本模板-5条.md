## 模板一：口播干货（知识博主）
```
0–3s  钩子：别再 [XXX] 了，正确做法是……
3–15s 痛点：你是不是也 [XXX]？
15–40s 方法：第1步…第2步…第3步（每步一句）
40–50s 收尾：照做就行，关注我学更多 [XXX]
```
**要点**：一句话一个信息点，别堆。

## 模板二：种草测评
```
0–3s  钩子：测评了 [N] 款 [XXX]，只有这 1 个值得买
3–20s 对比：A 怎么样（缺点）/ B 怎么样（缺点）
20–40s 推荐：C 为什么好（3 个理由）
40–50s 购买建议：适合谁 / 不适合谁
```
**要点**：先踩后捧，真实感强。

## 模板三：教程拆解
```
0–3s  钩子：30 秒教你 [XXX]
3–45s 步骤：打开 XXX → 点 XXX → 调 XXX（边做边说）
45–55s 提醒：注意 XXX 这个坑
```
**要点**：屏幕录屏 + 同步解说，比纯口播清晰。

## 模板四：Vlog 叙事
```
0–3s  钩子：今天干了一件 [形容词] 的事
3–30s 过程：发生了什么（有转折）
30–50s 感受：我学到了 / 想说
50–55s 互动：你们有没有过 [XXX]？
```
**要点**：有情绪起伏，别流水账。

## 模板五：治愈/氛围
```
0–3s  钩子：累了就来 [XXX] 待一会
3–50s 画面 + 轻解说 / 纯字幕 + 音乐
50–55s 一句温柔收尾
```
**要点**：画面和音乐 > 文案，文案少而准。
