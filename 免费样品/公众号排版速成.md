## 一、先记住 4 条铁律（比学工具重要）
1. **字号 15–16px**，行间距 1.75–2.0，字间距 1–1.5px。手机上太小/太挤都没人看完。
2. **一段不超过 5 行**，多分段。读者是滑屏，不是读书。
3. **重点句单独成行 + 加粗/换色**，别埋在长句里。
4. **两端对齐 + 首行不缩进**（公众号阅读习惯），段间空一行。

---

## 二、3 个能直接抄的样式（在公众号编辑器"两端对齐"里粘贴）

**① 小标题条**
```
◆ 今天聊这件事
```
（用 ◆ ● ▍ 等符号做视觉锚点，比纯文字标题抓眼）

**② 金句卡片（引用样式）**
```
"真正拉开差距的，不是知道多少，而是动手做了多少。"
```
（选中文字 → 点编辑器"引用" → 调成浅底色，金句独立成块）

**③ 要点清单**
```
✅ 第一步：XXX
✅ 第二步：XXX
✅ 第三步：XXX
```
（用 ✅ ⭐ ▶ 做项目符号，比 1.2.3. 更有呼吸感）

---

## 三、配色公式（不踩雷）
- **正文**：#3f3f3f（深灰，比纯黑柔和）
- **强调**：#e63946（红）或 #2f6bff（蓝），全文只用一个强调色
- **背景块**：#f7f7f7（浅灰）或品牌浅色
- **禁忌**：全文超过 3 种颜色、荧光色、大红大绿
