# AI 短视频脚本怎么写？5 种结构模板 + 实战案例

> 短视频 80% 的成败在脚本。本文给 5 种可直接填空的模板，照抄就能拍。

---

## 一、先记住：前 3 秒定生死
用户划走只要 0.5 秒。开头必须抛**反差 / 利益 / 疑问**之一，否则后面再好也白搭。

---

## 二、5 种结构模板（填空即用）

### 1. 口播干货（知识博主）
```
0–3s  钩子：别再 [XXX] 了，正确做法是……
3–15s 痛点：你是不是也 [XXX]？
15–40s 方法：3 步走（每步一句）
40–50s 收尾：关注我学更多 [XXX]
```

### 2. 种草测评
```
0–3s  钩子：测评了 N 款 [XXX]，只有这 1 个值得买
3–20s 对比：A 的缺点 / B 的缺点
20–40s 推荐：C 的 3 个理由
40–50s 建议：适合谁 / 不适合谁
```

### 3. 教程拆解
```
0–3s  钩子：30 秒教你 [XXX]
3–45s 步骤：打开→点→调（边做边说）
45–55s 提醒：注意这个坑
```

### 4. Vlog 叙事
```
0–3s  钩子：今天干了一件 [形容词] 的事
3–30s 过程：有转折
30–50s 感受：我学到了
50–55s 互动：你们有没有过 [XXX]？
```

### 5. 治愈氛围
```
0–3s  钩子：累了就来 [XXX] 待一会
3–50s 画面 + 轻音乐 + 少字幕
50–55s 一句温柔收尾
```

---

## 三、写脚本的 3 个禁忌
1. 开头 3 秒没钩子 → 划走率 80%。
2. 单句超 25 字 → 念着累、听着乱。
3. 一个视频讲 3 个以上主题 → 观众记不住。

---

## 四、实操流程（用 AI 提速）
1. 定主题 → 2. 选上面 1 种模板 → 3. 让 AI 按模板生成 3 版 → 4. 你挑一版改口语化 → 5. 拍/剪。
一套流程 10 分钟出脚本。
