# 公众号排版从 0 到 1（新手不出错指南）

很多人文章写得好，发出去却"像没排过版"——读者三行就划走。排版不是美化，是**降低阅读阻力**。

照着做，10 分钟搞定一篇专业排版。

## 一、字号与间距（黄金参数）

| 项目 | 推荐值 |
|---|---|
| 正文字号 | 15–16 px |
| 行间距 | 1.75–2.0 倍 |
| 段间距 | 空一行（或 15–20 px） |
| 字间距 | 1–1.5 px |
| 两端对齐 | 开 |

记不住？直接抄这个组合：**15px / 1.8 行距 / 两端对齐 / 页边距 10**。

## 二、配色：一套就够

新手最容易花。记住：**全文一种正色 + 一种强调色**。
- 正文：深灰 `#3f3f3f`（别用纯黑，刺眼）
- 强调/小标题：一个品牌色（如 `#e63946` 红，或 `#2a9d8f` 绿）
- 背景：纯白或极浅灰

## 三、小标题是灵魂

手机屏上，读者靠小标题"跳读"。每 300–500 字一个加粗小标题，用强调色。文章结构一眼清。

## 四、图片与留白

- 图宽统一（建议 900px 或更窄，避免撑破手机屏）
- 图上文下留白，别贴着文字
- 封面图 900×383（公众号比例），标题压图下半部

## 五、三个别碰的雷

- ❌ 满屏大红大绿
- ❌ 花字 / 艺术字（手机上糊成一团）
- ❌ 长段落不分（超过 5 行就拆）
